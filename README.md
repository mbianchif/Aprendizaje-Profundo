# Aprendizaje-Profundo

Este repositorio contiene los *notebooks* utilizados en el curso para experimentar con distintos modelos de **aprendizaje profundo** y **modelos clásicos de redes neuronales**.

## Modelos incluidos

* **Perceptrones Multicapa (MLP)**
* **Mapas Autoorganizados de Kohonen (SOM)**
* **Redes de Hopfield**
* **Máquinas de Boltzmann y RBM**
* **Redes Neuronales Convolucionales (CNN)**

Cada notebook implementa y entrena el modelo correspondiente, y muestra ejemplos de uso, visualizaciones y análisis básicos.
