\subsection{Compresión de Red: Serialización Sparse}

Para optimizar el volumen de comunicación en red, el sistema utiliza un esquema de serialización de gradientes \emph{sparse} (o dispersa)~\cite{aji-heafield-2017-sparse}, el cual limita el intercambio a los componentes de mayor relevancia. El parámetro $r \in [0, 1)$ determina la proporción de compresión: a mayor $r$, menor es el tamaño del mensaje transmitido.

La cardinalidad efectiva $k$ del mensaje se calcula mediante:

\begin{equation}
k = \text{round}\left(|g| \cdot (1.0 - r)\right)
\end{equation}

El valor $k$ selecciona los $k$ elementos de mayor magnitud absoluta dentro del tensor de gradientes local. Todo valor que alcance o supere dicho umbral se incorpora al mensaje. En estos experimentos se fijó $r = 0.5$, filtrando el \SI{50}{\percent} de los componentes para reducir el tránsito en red. Los elementos no transmitidos se acumulan en un gradiente residual local para ser considerados en la siguiente actualización.

\subsection{Emulación de Red con Pumba}

Para evaluar el desempeño en un escenario distribuido realista sobre redes residenciales, se empleó Pumba ~\cite{pumba}, una herramienta de emulación de condiciones de red y pruebas de resiliencia. Mediante la integración con \emph{docker-compose}, se inyectaron restricciones de ancho de banda, retardo (latencia con distribución Pareto) y pérdida correlacionada de paquetes sobre la interfaz de red de los contenedores, replicando el comportamiento de una conexión hogareña típica.
