# Hopfield

El TP consiste en una guía de ejercicios donde se modela, entrena y valida el entrenamiento de una red de Hopfield utilizando imágenes en blanco y negro para evaluar cuan bien almacena las imágenes aprendidas.

## Extracción de Imágenes

Para extraer las imágenes ejecutar:
```sh
unzip images.zip
mkdir images
mv *.bmp images/
```

## Ejecución del Notebook

Para correr el notebook de forma local ejcutar:
```sh
uv run jupyter notebook
```
